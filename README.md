# Benjamin Spencer

**Head of Medicines (Inequality & Population Health)** – NHS Bath and North East Somerset, Swindon and Wiltshire, Dorset and Somerset ICB Cluster

NHS pharmacist with a passion for improving outcomes through medicines, data and innovation.
